Evaluating the Fairness of the 9-Point Tennis Tiebreaker Using Monte Carlo Methods

This blog post is based on a work I did in Fall 2022 as an analyst with the Cornell Sports Analytics Club.

Background

Under most standard tennis scoring formats, tiebreakers are used to decide sets that are tied after a fixed number of games (7-point tiebreaker) or to decide matches that are tied one to one in sets (10-point tiebreaker). In both cases, the first player to that number of points wins but they must be ahead by two points or the tiebreaker continues. In addition, both tiebreaker formats use the “A-B-B-A” serving format in which the player/team who serves the first point also serves the fourth, fifth, eighth, ninth, and so on.

history, length

Let's now go over tennis concepts that are important in this project:

  • At almost every level of tennis, the player who is serving has an advantage.
  • A "hold" is defined as the server their service game (or point in a tiebreaker).
  • Likewise, a "break" is defined as the returner winning the game or tiebreaker point.
  • When a returner is within one point of winning a game, the next point is said to be a “break point”.
  • Likewise, when either player is within one point of winning a match, the next point is said to be a “match point.” match point dynamic

In this project, I tried to measure the fairness of three different tiebreak formats: the 7-point and 9-point formats established above, as well as a hybrid "mixed" format. The mixed format is a fixed-length, first to five tiebreak like the 9-point format, but it uses the serving pattern of the 7-point tiebreak.

Tiebreak Fixed Length? Serve Format Points to Win
Seven Point No ABBAABB… 7+
Nine Point Yes AABBAABBB 5
Mixed Yes ABBAABBAA 5

Going forward, the player or doubles team which serves first in a tiebreak will be referred to as "Player A" and the other player/team will be referred to as "Player B". Moreover, doubles matches will not be treated differently, and each team is treated as a single entity.

Monte-Carlo Methods

In computer science and statistics, Monte Carlo methods are a broad class of algorithms that rely on repeated random sampling to achieve a result. These methods are employed when the goal is to estimate a quantity that is difficult to calculate directly. For example, a good way to calculate the value of π from scratch directly is not immediately obvious. However, this is a simple task using randomness. Since a random point with x and y coordinates between 0 and 1 has a π/4 probability of being inside the first quadrant of the unit circle, one can sample a large number of such points and multiply the proportion of points inside the unit circle by 4 to get π. This project uses the same principle: instead of random points, I simulate many random tiebreaks to estimate the likelihood of different outcomes, since the problem is too complex to solve with a simple formula.

Analysis

Most of the analysis part of this project consists of several "experiments" or "scenarios".

First however,

To set some context for the simulations, I looked at how ATP Top 100 players performed in 2021. Using data from Ultimate Tennis Statistics, I calculated average hold rates, return rates, break point stats, and game lengths. These numbers also serve as parameters for the simulations.

  • Average Service Point Win %: 63.73% (91 players, 9 with no data)
  • Average Return Point Win %: 36.97% (91 players)
  • Average Break Points Saved %: 61.58% (91 players)
  • Average Break Points Converted %: 39.33% (91 players)
  • Average Points per Service Game: 6.40 (87 players)
  • Average Points per Return Game: 6.42 (87 players)
  • Average Game Time: 4.84 minutes (18 players)

Notice that break point stats are slightly skewed compared to overall point stats: break points saved are about 2.15% lower than the average service point win rate, and break points converted are about 2.36% higher than the return point win rate. On average, that’s a 2.26% swing. These small differences highlight the pressure of break points and potentially extend to match points.
